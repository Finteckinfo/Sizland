# Sizland (`www.siz.land`)

Sizland is infrastructure for sovereign remote work: public profiles, land and asset listings, and identity that stays on the user’s device.

## Related products (do not mix these up)

| Host | Product |
|------|---------|
| [www.siz.land](https://www.siz.land) | Public Sizland site |
| [wallet.siz.land](https://wallet.siz.land) | **SizWallet** — DID-first identity wallet on Base. Self-custody, passkeys, `.siz` profiles, Element Pay. **Not** a SIZ token shop. |
| [buy.siz.land](https://buy.siz.land) | Land / asset marketplace (Sizland identity client, not a second wallet) |

SizWallet is **not** an Algorand token-distribution frontend. It does not use Pera, Defly, Lute, or WalletConnect to buy SIZ, and it does not take Stripe or Paystack payments for tokens.
